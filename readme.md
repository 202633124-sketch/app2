# 📊 단어 빈도 및 감성 시각화 프로그램 (Word Frequency & Sentiment Visualizer)

Streamlit과 Kiwipiepy 형태소 분석기를 활용하여 텍스트 파일(.txt)을 전처리하고, 단어 빈도 분석 및 감성 분석 결과를 다양한 시각화(막대그래프, 워드클라우드, 원그래프)로 제공하는 웹 애플리케이션입니다.

---

## 📌 주요 기능

1. **텍스트 파일(.txt) 업로드 & 내용 확인**
   - 사용자 텍스트 파일 읽기 및 원본 내용 표시
2. **사용자 사전 등록**
   - 쉼표(`,`)로 단어를 입력하여 복합어나 신조어가 쪼개지지 않도록 Kiwi 사용자 사전에 등록
3. **한국어 전처리 (Kiwi)**
   - 형태소 분석을 통해 2글자 이상의 핵심 명사 추출
   - 감성 분석을 위한 동사/형용사의 기본형(~다) 추출
4. **단어 빈도 분석 & 시각화**
   - 슬라이더를 통해 상위 단어 개수(5~50개) 조절
   - 단어 빈도표(DataFrame) 및 가로 막대그래프 제공
   - 워드클라우드(WordCloud) 시각화
5. **감성 분석**
   - 긍정/부정 감성 사전을 바탕으로 단어 수 집계 및 목록 표시
   - 긍정·부정 비율 원그래프(Pie Chart) 제공
   - NanumGothic 폰트를 활용한 한글 깨짐 방지
